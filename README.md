# ระบบจัดสอนแทน - โรงเรียนชุมชนบ้านวังพิกุล (Firebase Edition)

เว็บแอพพลิเคชันบริหารจัดการตารางสอนแทนคุณครู จัดทำขึ้นตามระเบียบและแบบฟอร์มเอกสารทางราชการของ **โรงเรียนชุมชนบ้านวังพิกุล** 
ทำงานร่วมกับ **Google Firebase (Cloud Firestore)** ซึ่ง **ไม่มีการปิดหรือ Pause ระบบแม้จะไม่ได้ใช้งานนานเป็นเดือนหรือช่วงปิดเทอม** พร้อมโควต้าฟรีตลอดชีพ และรองรับการทำงานออฟไลน์ในตัว

---

## 🌟 จุดเด่นของระบบ

1. **ฐานข้อมูล Google Firebase Firestore (Always-Online 24/7):**
   - **ไม่ปิดระบบอัตโนมัติ:** หมดปัญหาโปรเจกต์หลับช่วงปิดเทอมหรือวันหยุดยาว เปิดเมื่อไหร่ก็ติดทันที
   - **โควต้าฟรี (Spark Plan) มหาศาล:** อ่าน 50,000 ครั้ง/วัน, เขียน 20,000 ครั้ง/วัน (รร.ใช้จริงไม่ถึง 1%)
   - **ซิงค์ข้อมูลเรียลไทม์:** เมื่อบันทึกจากเครื่องหนึ่ง เครื่องอื่นเห็นข้อมูลทันที
   - **ระบบสำรองในเครื่อง (LocalStorage):** หากยังไม่ได้เชื่อมต่อเน็ตหรือ Firebase ก็ยังทำงานและบันทึกในเครื่องได้ 100%

2. **หน้าจัดสอนแทน:**
   - คำนวณวันและดึงคาบสอนจริงของครูที่ลาอัตโนมัติ
   - **กรองเฉพาะครูที่ "ว่าง" ในคาบนั้น** พร้อมแสดงจำนวนครั้งที่เคยสอนแทนมาแล้ว เพื่อกระจายงานอย่างเป็นธรรม
   - พิมพ์ PDF ขนาด A4 ตรงตามแบบฟอร์มราชการของโรงเรียนชุมชนบ้านวังพิกุล
   - **ระบบหน้าอัจฉริยะ:** ลา 1 คน พิมพ์ 1 ตาราง / ลา 2 คน พิมพ์ 2 ตารางใน 1 แผ่น / ลา 3 คน แบ่ง 2 คนแผ่นแรก 1 คนแผ่นที่สอง

3. **หน้าวันลาและการสอนแทน:**
   - **นับสถิติการลาครบทุกประเภท:** ติดตามจำนวนครั้งการลาของครูแต่ละท่าน แยกเป็น **ไปราชการ**, **ลากิจ**, **ลาป่วย** และยอดรวม
   - **นับจำนวนครั้งการสอนแทน:** Real-time ทุกครั้งที่ได้รับมอบหมาย
   - **ระบบจัดเรียงหลากหลาย:** เรียงตามสอนแทนมาก/น้อย, ลามาก/น้อย (รวมทุกประเภท), ไปราชการมากสุด, ลากิจมากสุด, ลาป่วยมากสุด หรือตามตัวอักษร ก-ฮ
   - **ดูประวัติรายบุคคล:** แยกแท็บประวัติการสอนแทน และประวัติการลา (ระบุวันที่, ประเภทการลา, คาบที่ได้รับการสอนแทน และผู้สอนแทน) พร้อมปุ่มลบรายการ

4. **หน้าแอดมิน (PIN: 0000) สไตล์ Spreadsheet:**
   - ตารางแก้ไขตารางสอน จันทร์–ศุกร์ คาบ 1–7 คล้าย Excel พิมพ์แก้ไขและกดบันทึกได้ทันที
   - ตั้งค่าเวลาคาบเรียน ข้อมูลโรงเรียน และชื่อผู้บริหาร
   - เชื่อมต่อ Firebase และกด **"อัปโหลดข้อมูลเริ่มต้น 30 ครู ขึ้น Firebase"** ได้ในคลิกเดียว

## 🔥 วิธีสมัครและเชื่อมต่อ Firebase (ใช้เวลาเพียง 2 นาที)

1. เข้าเว็บ [**console.firebase.google.com**](https://console.firebase.google.com) ล็อกอินด้วย Gmail
2. กด **"Create a project"** (ตั้งชื่อโปรเจกต์ เช่น `wangpikul-teach`) ➔ กด Next จนเสร็จ
3. ที่เมนูซ้ายมือ ไปที่ **Build ➔ Firestore Database** ➔ กดปุ่ม **"Create database"**
   - เลือก Location: `asia-southeast1 (Singapore)` หรือค่าเริ่มต้น
   - เลือก **Start in test mode** แล้วกด Enable
   - *(หรือไปที่แท็บ Rules คัดลอกโค้ดจากไฟล์ `firestore.rules` ไปวางแล้วกด Publish)*
4. ไปที่ไอคอนรูปฟันเฟือง ⚙️ ด้านบนซ้าย เลือก **Project settings**
5. เลื่อนลงมาที่หัวข้อ "Your apps" ➔ กดที่ไอคอนเว็บ **`</>`** (Web)
6. ตั้งชื่อแอพแล้วกด **Register app** ➔ ระบบจะแสดงบล็อกโค้ด:
   ```javascript
   const firebaseConfig = {
     apiKey: "AIzaSy...",
     authDomain: "wangpikul-teach.firebaseapp.com",
     projectId: "wangpikul-teach",
     storageBucket: "wangpikul-teach.appspot.com",
     messagingSenderId: "...",
     appId: "..."
   };
   ```
7. เปิดหน้าเว็บระบบสอนแทน ➔ ไปที่แท็บ **หน้าแอดมิน (PIN: 0000)** ➔ เลือกแท็บ **เชื่อมต่อ Firebase** 
8. คัดลอกบล็อกโค้ดด้านบนมาวางในช่อง ➔ กด **"บันทึกการเชื่อมต่อ Firebase"**
9. กดปุ่ม **"อัปโหลดข้อมูลเริ่มต้น 30 ครู ขึ้น Firebase"** เพื่อส่งตารางสอนขึ้นคลาวด์ เป็นอันเสร็จสมบูรณ์!

## 🌐 การฝากโฮสติ้งฟรี (Hosting)

### 1. Firebase Hosting (แนะนำ - ฟรี & เร็วมาก)
- สามารถใช้ Firebase Hosting ที่มาพร้อมกับโปรเจกต์ Firebase ได้ฟรี โดยติดตั้ง Firebase CLI:
  ```bash
  npm install -g firebase-tools
  firebase login
  firebase init hosting
  firebase deploy
  ```
- จะได้ URL เช่น `https://wangpikul-teach.web.app` ให้ครูทุกคนเปิดใช้งานผ่านมือถือหรือคอมพิวเตอร์ได้ทุกที่

### 2. Vercel / Netlify / GitHub Pages
- ลากโฟลเดอร์นี้ขึ้น GitHub แล้วผูกกับ Vercel หรือ Netlify ได้ฟรี 100% เช่นกัน
